# Customer_behavior_analysis

📌 Project Overview

Data Analysis Project Showcasing Customer Behavior Analysis using Python, SQL, MS Excel, Power BI

The goal of this project is to simulate a end-to-end data analytics workflow, demonstrating the ability to translate raw data into strategic business intelligence by:

✅ Data Preparation,Modeling & Exploratory Data Analysis (Python): Cleaned and transformed the raw dataset for analysis.

✅ Data Analysis (SQL): Simulated business transactions, and run queries to extract insights on customer segments, loyalty, and purchase drivers.

✅ Visualization & Insights (Power BI): An interactive dashboard that highlights key patterns and trends, enabling stakeholders to make data-driven decisions.
